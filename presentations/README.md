Use desktop PowerPoint in Slide Show mode. Background videos are set to start automatically and loop. Advance manually with Right Arrow, a presentation remote, or the small lower-right arrow. The PowerPoint contains its media; no network, audio API or external video files are required. Editing view and PDF show still posters.
