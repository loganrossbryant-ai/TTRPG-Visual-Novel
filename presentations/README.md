## Presenting

Use desktop PowerPoint in Slide Show mode. Background videos are set to start automatically and loop. Advance manually with Right Arrow, a presentation remote, or the small lower-right arrow. The PowerPoint contains its media; no network, audio API or external video files are required. Editing view and PDF show still posters.

Zara Quinn is the editable fictional default for the name-match clue. Record a personal Earth object in Session 1 and use that callback in Session 10. Carry the actual Session 8 sacrifice forward. The teacher runs the GM bible script; the deck supplies atmosphere and evidence. Orientation schematics are illustrative, not scale maps.

Package structure, all media decoding and office-rendered layouts passed checks. Actual Microsoft desktop PowerPoint playback has not been tested here. Test the first chapter on the classroom machine before class. Web and alternative viewers may treat autoplay or looping differently.
